# Arrowword Flutter prototype

Early Arrowword-style mobile puzzle prototype: English answers and Turkish clues. “Arrowword” is a working project name, not a final consumer-facing name.

This milestone has one manually authored 9×9 puzzle. Automatic puzzle generation, puzzle selection, backend, accounts, analytics, and monetization are intentionally not implemented.

```bash
flutter pub get
flutter run
flutter analyze
flutter test
```
