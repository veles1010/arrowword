# Medium / Hard pre-freeze content review — 2026-10-06

All 600 clue–answer pairs were read individually for meaning, Turkish phrasing,
learner fairness, synonym collisions and mobile length; this was not a regex-only
review. **42 Medium and 29 Hard clues changed. No answers, IDs, ordering, tags or
WordDifficulty metadata changed.** Both banks remain 300 new A–Z answers of
4–7 letters, disjoint from each other and Easy. No generator, track configuration,
sequence, seed, scoring, Daily or persistence changes were needed in this audit.

The common issue was a broad definition that covered several near-synonyms.
Concrete contexts were preferred to obscure vocabulary substitutions. Clues are
not cryptic and do not encode spelling/length. Crossings still legitimately resolve
close synonyms; no semantic audit can certify that every clue has one conceivable
English paraphrase. Familiar bridge words remain intentional: difficulty should
not become an obscurity contest. Actual learner-level calibration needs playtesting.

## Ten hardest/fuzziest Medium candidates reviewed

| Candidate | Decision / remaining risk |
|---|---|
| ENGINE / MOTOR | Combustion/piston versus electrical rotation contexts; these are overlapping words, not an absolute engineering taxonomy. |
| COLUMN / PILLAR | COLUMN now uses the newspaper sense; PILLAR retains structural support. Equal-length collision removed. |
| QUARTZ | Replaced generic hardness with familiar clock-crystal use; mineral recall still moderately difficult. |
| NICKEL | Added coins and steel context; gümüşümsü alone was not distinctive enough. |
| SLATE | Roof/blackboard context distinguishes it from SHALE; stone vocabulary remains a learning edge. |
| COCOA | Roasted powdered product rather than generic bean product; avoids treating CACAO as interchangeable. |
| RAVEN / CROW | RAVEN now has a thick bill and large corvid frame; bird-name recall still needs crossings. |
| MEADOW / PRAIRIE | Flowered meadow versus broad North American grassland; geographical meaning, not a trivia question. |
| CHOICE / OPTION | Decision-making act versus available alternative. Near-synonym context remains important. |
| VEST | Broader neutral garment description avoids requiring one country's underwear/waistcoat usage. Crossings required; not fully unique. |

Medium 11: GATHER, FACT, MAPLE, CLEAR, HAWK, ALLOW, STORK, WAGON, AVENUE,
DOME. GATHER has four neighbors; DOME is the only leaf. The main loop is integrated,
but STORK's upper arm and DOME's right edge spread it across all ten columns.
The revised gathering/maple/clear/wagon clues are fair; HAWK remains a broad bird
description best resolved through crossings. This is a valid phone-width edge case,
not a showcase board. It is retained pending real small-screen reading playtest.

Hard 19: ACRE, LURE, FLOAT, HALO, WHIM, BLUNT, TRUDGE, CLEAVE, WARY, ABYSS.
Nine edges connecting ten answers form a tree. WHIM and ABYSS are the leaves;
several central answers have only two neighbors. The long CLEAVE/right-hand arm
reduces visual integration. CLEAVE/TRUDGE/WHIM are appropriately challenging;
ACRE's unit clue relies on length/crossings, not memorized conversion. This is
structurally and semantically acceptable but below desired visual richness.

No content defect explains either layout. Clue-only repairs cannot change them.
No index exceptions, extra retries or quality tuning were added: two isolated
outliers do not justify changing the deterministic policy. All strict rules remain
mandatory. Both edge cases belong in manual playtest before difficulty UI.

Medium has 168 six/seven-letter words versus Hard's 102. Its unused words have
157 / 269.68 / 297 min/mean/max partners, compared with 259.15 mean for the whole
bank. Hard unused mean is 268.02 versus 249.19 overall. No word falls below the
100-partner gate; aggregate isolation therefore does not explain unused entries.
This does not prove every word can appear in a ten-answer board.

The unchanged support ranking divides neighbor count by word length; the unchanged
quality comparison favors compact, narrow, highly crossed boards. Longer words
consume more constrained grid/run space. Medium's higher attempt count (3.2 versus
2.5) is consistent with longer targets needing more support. These are supported
structural explanations, not a causal ablation of generator branch ranking.
Unseen after 30 puzzles is **not** evidence of permanent unusability; no answer was
replaced simply to increase the percentage. No structurally catastrophic candidate
was identified. Observe a longer curriculum later rather than sacrificing content.
